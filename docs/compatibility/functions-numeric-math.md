# Numeric and math functions

Numeric conversion, arithmetic, trigonometric, random, and rounding functions.

In this table, "row-backed numeric contexts" means single-table row-scalar
projection, supported comparison predicates, `ORDER BY` expression keys,
arithmetic/control-flow operands, and nested covered numeric calls over numeric
or nonbinary string-family descriptor columns, integer/string/boolean/`NULL`
literals, and supported row-scalar numeric operands. Row-backed execution still
normalizes negative-zero floating-point display through SQLite result
extraction.

| Function or operator | Status | Notes |
| --- | --- | --- |
| `/` | 🟡 | Limited no-source/`DUAL` top-level scalar division and limited `DO` expression execution over signed-64 scalar arithmetic operands, returning four fractional digits for integer/integer inputs; no nested slash composition, table-backed expression support, decimal/float/string/hex/bit conversion, or expression metadata |
| `ABS()` | 🟡 | Scalar and row-backed numeric contexts; `ABS(-9223372036854775808)` reports MySQL overflow; row string coercion emits MySQL warnings; gaps: binary/JSON/temporal coercion and exact expression metadata |
| `ACOS()` | 🟡 | Scalar and row-backed numeric contexts; values outside `-1..1` return `NULL`; row string coercion emits MySQL warnings; gaps: binary/JSON/temporal coercion and exact expression metadata |
| `ASIN()` | 🟡 | Scalar and row-backed numeric contexts; values outside `-1..1` return `NULL`; row string coercion emits MySQL warnings; gaps: binary/JSON/temporal coercion and exact expression metadata |
| `ATAN()` | 🟡 | Scalar and row-backed numeric contexts for one-argument `ATAN(value)` and MySQL-accepted one-argument `ATAN2(value)`; row string coercion emits MySQL warnings; gaps: binary/JSON/temporal coercion and exact expression metadata |
| `ATAN2(), ATAN()` | 🟡 | Scalar and row-backed numeric contexts for two-argument `ATAN(y, x)` / `ATAN2(y, x)`; row string coercion emits MySQL warnings; gaps: binary/JSON/temporal coercion and exact expression metadata |
| `BIN()` | 🟡 | Limited scalar/`DO` plus single-table row-scalar projection/nesting, comparison predicates, and `ORDER BY` expression keys over integer-domain operands; returns unsigned 64-bit base-2 text with no leading zeroes; gaps: string/decimal/float/hex/bit row coercion, non-ASCII collation parity, and exact expression metadata |

| `CONV()` | 🟡 | Limited scalar/`DO` plus single-table row-scalar projection/nesting, comparison predicates, and `ORDER BY` expression keys over integer-domain value/base operands with absolute bases `2..36`; returns uppercase MySQL-style signed/unsigned base-conversion text; gaps: string/decimal/float/hex/bit row coercion, non-ASCII collation parity, and exact expression metadata |

ORDER BY RAND()` / `RAND(seed)` with optional direction and supported `LIMIT`; table-backed seed literals admit integer, boolean, and `NULL`, and table-backed descriptor seeds additionally admit warning-free integer `CAST`/`CONVERT` column expressions, while no-source scalar seed coercion additionally admits fixed/approximate numeric literals rounded to integer seeds, ordinary string literals converted with MySQL-style integer-prefix warnings, and existing scalar `NULLIF()` plus integer `CAST`/`CONVERT` seed expressions; values are doubles in `[0, 1)`, seeded table-backed integer-literal expressions advance per row, and descriptor-derived seeds reinitialize per row.
