# SQL table DDL

Table lifecycle, table-specific DDL, CREATE TABLE options, and ALTER TABLE
actions.

## Statement surface

| Feature | Status | Notes |
| --- | --- | --- |
| `ALTER TABLE` | 🟡 | Limited single-action persistent base-table `ALTER TABLE ... RENAME [TO\|AS]`, append-only `ALTER TABLE ... ADD [COLUMN]`, single-column `ALTER TABLE ... DROP [COLUMN]`, single-column `ALTER TABLE ... RENAME COLUMN ... TO ...`, single-column `ALTER TABLE ... MODIFY [COLUMN] ...`, single-column `ALTER TABLE ... CHANGE [COLUMN] old_col new_col ...`, single-column `ALTER TABLE ... ALTER [COLUMN] ... SET DEFAULT ...` / `DROP DEFAULT`, single-column `ALTER TABLE ... ALTER [COLUMN] ... SET VISIBLE\|INVISIBLE`, fixed metadata no-op `ALTER TABLE ... [DEFAULT] CHARSET` / `CHARACTER SET utf8mb4` plus `COLLATE utf8mb4_0900_ai_ci`, physical row-order rebuild `ALTER TABLE ... ORDER BY ...`, and physical table rebuild `ALTER TABLE ... FORCE` forms only; see [ALTER TABLE actions](#alter-table-actions) |
| `CREATE TABLE` | 🟡 | Limited persistent base-table creation: optional `IF NOT EXISTS`, explicit integer-family columns (`TINYINT`, `SMALLINT`, `MEDIUMINT`, `INT`/`INTEGER`, `BIGINT`), the `INT1`/`INT2`/`INT3`/`INT4`/`INT8` plus `BOOL`/`BOOLEAN` aliases, and limited `VARCHAR(0..255)` columns, optional deprecated display width `0..255` before optional single `SIGNED` or `UNSIGNED` for integer-family and `INT*` aliases, `NULL`/`NOT NULL`, optional `DEFAULT NULL`, optional descriptor-owned decimal integer/`TRUE`/`FALSE` defaults within the current signed-64 physical range, optional single-column integer-family `PRIMARY KEY`, optional `AUTO_INCREMENT` on that primary-key column, optional explicit `ENGINE [=] InnoDB`, optional `AUTO_INCREMENT=N` initial counter option, optional fixed default `utf8mb4` / `utf8mb4_0900_ai_ci` table charset/collation options, limited empty descriptor cloning with `CREATE TABLE ... LIKE`, and limited descriptor-inferred row copying with `CREATE TABLE ... SELECT`; display width emits warning 1681 and only signed `TINYINT(1)`/`INT1(1)` plus `BOOL`/`BOOLEAN` persist as `tinyint(1)` metadata; existing-table `IF NOT EXISTS` is a no-op with `Note 1050`; no other options, composite keys, `VARCHAR` keys, named constraints, secondary indexes, `CREATE TABLE` auto-increment defaults, string defaults, expression defaults, `VISIBLE`/`INVISIBLE` column definitions, temporary tables, or generated invisible primary keys |
| `CREATE TEMPORARY TABLE` | ❌ | Session-scoped table lifecycle and name shadowing |
| `CREATE TABLE ... LIKE` | 🟡 | Limited empty persistent base-table descriptor clone for MyLite-owned integer/null and `VARCHAR(0..255)` descriptors, including nullability, defaults, visibility, column order, the current single-column integer primary-key descriptor, and its auto-increment attribute with the target counter reset to `1`; supports optional `IF NOT EXISTS` and parenthesized `(LIKE source)` form; no row copying, temporary tables, views, secondary indexes, constraints beyond the current primary key, generated columns, table options beyond the reset counter, or full MySQL metadata cloning |
| `CREATE TABLE ... SELECT` | 🟡 | Limited descriptor-backed `CREATE TABLE [IF NOT EXISTS] target [AS] SELECT ... FROM source` for persistent base tables, reusing the current single-table source `SELECT` subset with optional table alias, `WHERE`, one-column `ORDER BY`, and `LIMIT`; target descriptors are inferred from selected source descriptor columns, preserve type/nullability/default metadata, make explicitly selected invisible source columns visible in the destination, do not copy primary keys or other indexes, copy rows atomically, and report inserted-row affected counts; no explicit destination column definitions, temporary tables, expression/literal projection, joins, indexes, constraints, table options, or full CTAS inference |
| `DROP TABLE` | 🟡 | Limited persistent base-table drop with comma-separated target lists and optional `IF EXISTS`; missing-table and missing-explicit-schema `IF EXISTS` forms are no-ops with `Note 1051`, duplicate targets fail before mutation, and non-`IF EXISTS` missing targets fail atomically; no `TEMPORARY`, `RESTRICT`, or `CASCADE` |
| `RENAME TABLE` | 🟡 | Limited persistent base-table rename with one or more left-to-right pairs from `baseline-table-rename-lifecycle` and `baseline-multi-table-rename-lifecycle`, including unqualified, schema-qualified, and cross-schema names plus statement rollback on pair failure; no temporary tables, views, triggers, metadata locks, foreign keys, or privilege semantics |
| `TRUNCATE TABLE` | 🟡 | Limited persistent base-table `TRUNCATE [TABLE] table_name` for unqualified and schema-qualified descriptor targets; empties physical rows, preserves descriptors, resets the current auto-increment counter subset to `1`, and reports zero affected rows; no implicit commits, temporary tables, partitions, foreign keys, triggers, locks, privileges, or physical storage rebuild semantics |
| Atomic DDL | 🟡 | Catalog descriptor rows and generated physical SQLite table changes commit or roll back atomically for the limited create/create-like/drop/rename/truncate and single-action alter rename/add-column/drop-column/rename-column/modify-column/change-column/order-by/force subsets only |
| Implicit commit boundaries | ❌ | Implicit commit boundaries |
| `IMPORT TABLE` | ❌ | Transportable tablespace import syntax, diagnostics |

## CREATE TABLE and table options

| Feature | Status | Notes |
| --- | --- | --- |
| Column definition grammar | 🟡 | Limited integer-family type, `INT1`/`INT2`/`INT3`/`INT4`/`INT8` aliases, bare `BOOL`/`BOOLEAN` aliases, limited `VARCHAR(0..255)`, optional unsigned decimal display width before optional single `SIGNED` or `UNSIGNED` for integer-family and `INT*` aliases, nullability, optional trailing `DEFAULT NULL` or decimal integer/`TRUE`/`FALSE` default literal for integer-family columns, optional `AUTO_INCREMENT` for one integer-family primary-key column, and optional trailing `PRIMARY KEY` for one integer-family column; no explicit string defaults, auto-increment defaults, named constraints, composite keys, or non-integer primary keys |
| Silent column specification changes | ❌ | Automatic column rewrites |
| Default expressions | 🟡 | Limited descriptor-owned defaults in supported integer-family column definitions and `ALTER TABLE ... ALTER [COLUMN] column_name SET DEFAULT ...` / `DROP DEFAULT`: `DEFAULT NULL` for nullable columns plus decimal integer literals with optional unary sign and `TRUE`/`FALSE` within MyLite's current physical signed-64 range, with dropped-default metadata preserved distinctly from implicit nullable defaults; supported by `CREATE TABLE`, `ADD COLUMN`, `MODIFY COLUMN`, `CHANGE COLUMN`, omitted-column `INSERT`, limited DML `DEFAULT` keyword values for current `INSERT`/`REPLACE` `VALUES` and `SET` paths plus one-assignment `UPDATE`, `SHOW COLUMNS`, and `SHOW CREATE TABLE`; `ALTER ... SET DEFAULT` on an `AUTO_INCREMENT` column follows MySQL's hidden-default behavior for omitted/default DML values without rendering a visible metadata default; no string/decimal/float/hex/bit defaults, general expression defaults, or `DEFAULT(col_name)` |
| Generated columns | ❌ | Generated column metadata |
| Invisible columns | 🟡 | Limited descriptor visibility for existing integer-family columns through `ALTER TABLE ... ALTER [COLUMN] column_name SET VISIBLE\|INVISIBLE`; invisible columns are omitted from `SELECT *` and no-column-list `INSERT ... VALUES`, remain explicitly addressable by supported `SELECT`, `INSERT`, `INSERT ... SET`, `UPDATE`, and `DELETE` forms, `DROP COLUMN` preserves at least one visible column, supported `MODIFY`/`CHANGE` definitions without visibility attributes make the target visible, and visibility renders in `SHOW COLUMNS`, `SHOW CREATE TABLE`, and limited `INFORMATION_SCHEMA.COLUMNS.EXTRA` metadata; no `CREATE`/`ADD`/`MODIFY`/`CHANGE` invisible column definitions, generated hidden columns, protocol flags, views, or index visibility |
| Generated invisible primary keys | ❌ | Invisible primary key metadata and hidden `my_row_id` table creation; limited scalar `@@sql_generate_invisible_primary_key` reads expose the fixed disabled baseline only |
| Primary key requirement enforcement | ❌ | `@@sql_require_primary_key` DDL effects are not implemented; limited scalar reads expose the fixed disabled baseline only |
| AUTO_INCREMENT columns | 🟡 | Limited `CREATE TABLE` support for one integer-family auto-increment column when it is the current single-column primary-key descriptor, with descriptor-owned counters, `CREATE TABLE ... AUTO_INCREMENT=N`, MySQL-compatible hidden defaults from existing `ALTER ... SET DEFAULT` syntax, `CREATE TABLE ... LIKE` attribute cloning and counter reset, `TRUNCATE` counter reset, `SHOW COLUMNS`, `SHOW CREATE TABLE`, `SHOW TABLE STATUS`, and limited `INFORMATION_SCHEMA.TABLES.AUTO_INCREMENT` / `INFORMATION_SCHEMA.COLUMNS.EXTRA` metadata; no `CREATE TABLE` auto-increment defaults, `ALTER TABLE ... AUTO_INCREMENT`, secondary-index auto columns, generated invisible primary keys, mixed-mode allocation gaps, `NO_AUTO_VALUE_ON_ZERO`, or replication lock modes |
| Table options: engine | 🟡 | Optional explicit `ENGINE [=] InnoDB` only; no alternate engines, engine substitution, or durable per-table engine metadata |
| Table options: charset/collation | 🟡 | Optional fixed default `CHARSET` / `CHARACTER SET utf8mb4` and `COLLATE utf8mb4_0900_ai_ci` options for the limited persistent `CREATE TABLE` subset plus fixed metadata no-op `ALTER TABLE ... [DEFAULT] CHARSET` / `CHARACTER SET utf8mb4` and `ALTER TABLE ... [DEFAULT] COLLATE utf8mb4_0900_ai_ci` for persistent base tables, with matching static `SHOW CHARACTER SET` / `SHOW COLLATION` rows; limited `VARCHAR` storage validates UTF-8 but no alternate defaults, descriptor charset metadata, conversion, collation comparison semantics, or full charset/collation catalogs |
| Table options: storage | ❌ | Storage option metadata |
| Table options: statistics | ❌ | Statistics option metadata |
| Table options: misc | ❌ | Misc table options |
| NDB comment options | ❌ | NDB comment syntax |
| Temporary table metadata | ❌ | Session isolation, name shadowing, and cleanup |

## ALTER TABLE actions

| Feature | Status | Notes |
| --- | --- | --- |
| `ADD COLUMN` | 🟡 | Limited append-only `ALTER TABLE table_name ADD [COLUMN] column_name column_type [NULL\|NOT NULL] [DEFAULT NULL\|DEFAULT integer_literal\|DEFAULT TRUE\|DEFAULT FALSE]` for persistent base tables; supports `TINYINT`, `SMALLINT`, `MEDIUMINT`, `INT`/`INTEGER`, `BIGINT`, `INT1`/`INT2`/`INT3`/`INT4`/`INT8` aliases, bare `BOOL`/`BOOLEAN` aliases, and limited `VARCHAR(0..255)`, with optional deprecated display width `0..255` before optional single `SIGNED` or `UNSIGNED` for integer-family and `INT*` aliases; existing rows backfill descriptor defaults, nullable no-default columns backfill `NULL`, integer not-null no-default columns preserve the current `0` backfill, and `VARCHAR` not-null no-default columns backfill empty strings while catalog metadata remains no-explicit-default; no positioning, multiple actions, parenthesized lists, string defaults, generated/invisible/auto-increment columns, added primary keys or other keys, constraints, algorithms, locks, temporary tables, or views |
| `DROP COLUMN` | 🟡 | Limited single-column `ALTER TABLE table_name DROP [COLUMN] column_name` for persistent base tables; removes the MyLite descriptor column, compacts later descriptor ordinals, preserves remaining row values, and emits MySQL-compatible diagnostics for unknown columns, attempts to drop the last column, attempts to drop the last visible column when other columns are invisible, and attempts to drop the current primary-key column; no multiple actions, table-qualified drop targets, key dependency updates, constraints, algorithms, locks, temporary tables, or views |
| `RENAME COLUMN` | 🟡 | Limited single-action `ALTER TABLE table_name RENAME COLUMN old_col TO new_col` for persistent base tables; preserves column id, ordinal position, integer type, nullability, and row values, supports exact same-name no-op and case-only spelling changes, and rejects duplicate, unknown, and current primary-key columns until key-aware column rename is specified; no multiple actions, table-qualified column names, type changes, dependency updates, algorithms, locks, temporary tables, or views |
| `CHANGE COLUMN` | 🟡 | Limited single-action `ALTER TABLE table_name CHANGE [COLUMN] old_col new_col integer_type [NULL\|NOT NULL] [DEFAULT NULL\|DEFAULT integer_literal\|DEFAULT TRUE\|DEFAULT FALSE]` for persistent base tables without primary-key descriptors; supports `TINYINT`, `SMALLINT`, `MEDIUMINT`, `INT`/`INTEGER`, `BIGINT`, `INT1`/`INT2`/`INT3`/`INT4`/`INT8` aliases, and bare `BOOL`/`BOOLEAN` aliases with optional deprecated display width `0..255` before optional single `SIGNED` or `UNSIGNED` for integer-family and `INT*` aliases, preserves column id and ordinal position, replaces name/type/nullability/default from the replacement definition, treats omitted nullability as nullable, makes the target visible because visibility attributes are not admitted, supports exact same-definition no-op and case-only spelling changes, validates existing integer/`NULL` row values inside the catalog mutation before descriptor replacement, keeps display-width-only, bool-alias range-equivalent, and default-only changes metadata-only except for physical column renames, and rebuilds descriptor-backed physical tables when type range or nullability changes; rebuilds currently require at least one unshadowed SQLite rowid alias; no positioning, non-integer types, multiple actions, table-qualified column names, generated/invisible/auto-increment columns, added primary keys or other keys, constraints, dependency checks, algorithms, locks, temporary tables, or views |
| `MODIFY COLUMN` | 🟡 | Limited single-action `ALTER TABLE table_name MODIFY [COLUMN] column_name integer_type [NULL\|NOT NULL] [DEFAULT NULL\|DEFAULT integer_literal\|DEFAULT TRUE\|DEFAULT FALSE]` for persistent base tables without primary-key descriptors; supports `TINYINT`, `SMALLINT`, `MEDIUMINT`, `INT`/`INTEGER`, `BIGINT`, `INT1`/`INT2`/`INT3`/`INT4`/`INT8` aliases, and bare `BOOL`/`BOOLEAN` aliases with optional deprecated display width `0..255` before optional single `SIGNED` or `UNSIGNED` for integer-family and `INT*` aliases, preserves column id and ordinal position, replaces nullability/default exactly as specified, makes the target visible because visibility attributes are not admitted, supports exact same-definition no-op and case-only spelling changes, validates existing integer/`NULL` row values inside the catalog mutation before descriptor replacement, keeps display-width-only, bool-alias range-equivalent, and default-only changes metadata-only, and rebuilds descriptor-backed physical tables when type range or nullability changes; rebuilds currently require at least one unshadowed SQLite rowid alias; no positioning, non-integer types, multiple actions, table-qualified column names, generated/invisible/auto-increment columns, added primary keys or other keys, constraints, dependency checks, algorithms, locks, temporary tables, or views |
| `ALTER COLUMN SET DEFAULT` | 🟡 | Limited catalog-only `ALTER TABLE table_name ALTER [COLUMN] column_name SET DEFAULT value` for persistent base tables and one unqualified integer-family descriptor column; `value` may be `NULL` for nullable columns, an in-range decimal integer literal with optional unary sign, `TRUE`, or `FALSE`; preserves existing row values and physical SQLite schema, reports zero affected rows and warnings, and updates descriptor defaults for later omitted-column inserts; defaults on `AUTO_INCREMENT` columns are hidden from `SHOW COLUMNS` / `SHOW CREATE TABLE` like MySQL, while ordinary column defaults render normally; no expression/string/decimal/float/hex/bit defaults, table-qualified columns, multiple actions, temporary tables, or views |
| `ALTER COLUMN DROP DEFAULT` | 🟡 | Limited catalog-only `ALTER TABLE table_name ALTER [COLUMN] column_name DROP DEFAULT` for persistent base tables and one unqualified descriptor column; preserves existing row values and physical SQLite schema, reports zero affected rows and warnings, stores a dropped-default descriptor state distinct from implicit nullable `DEFAULT NULL`, makes later omitted-column inserts fail, and renders MySQL-compatible `SHOW COLUMNS` / `SHOW CREATE TABLE` metadata; no table-qualified columns, multiple actions, temporary tables, or views |
| `ALTER COLUMN SET VISIBLE` / `SET INVISIBLE` | 🟡 | Limited catalog-only `ALTER TABLE table_name ALTER [COLUMN] column_name SET VISIBLE\|INVISIBLE` for persistent base tables and one unqualified descriptor column; preserves row values and physical SQLite schema, reports zero affected rows and warnings, prevents making every column invisible with MySQL error 4028, and drives `SELECT *`, implicit insert mapping, `SHOW COLUMNS`, and `SHOW CREATE TABLE`; no table-qualified columns, multiple actions, column-definition visibility syntax, generated invisible primary keys, protocol flags, temporary tables, or views |
| `RENAME TO` | 🟡 | Limited single-action persistent base-table `ALTER TABLE ... RENAME [TO\|AS]` through descriptor rename; supports unqualified, schema-qualified, cross-schema, and same-object no-op forms; no combined actions, temporary tables, views, triggers, options, locks, algorithms, privileges, or metadata side effects |
| `ORDER BY` | 🟡 | Limited single-action `ALTER TABLE table_name ORDER BY column_name [ASC\|DESC][, ...]` for persistent base tables without primary-key descriptors; resolves unqualified, target-table-qualified, and target-schema-table-qualified descriptor columns, rebuilds the physical SQLite table with `INSERT INTO temp SELECT ... ORDER BY ...`, reports copied rows, and leaves descriptors unchanged; no expression or ordinal order keys, temporary tables, mixed ALTER actions, indexes, clustering guarantees, storage-engine algorithm controls, locks, or privileges |
| `CONVERT TO CHARACTER SET` | ❌ | Column/table charset and collation conversion semantics |
| `DEFAULT CHARACTER SET` / `COLLATE` | 🟡 | Limited fixed metadata no-op `ALTER TABLE table_name [DEFAULT] CHARSET` / `CHARACTER SET utf8mb4` and `ALTER TABLE table_name [DEFAULT] COLLATE utf8mb4_0900_ai_ci` for persistent base tables; validates the fixed baseline names, preserves descriptors and rows, and reports zero affected rows/warnings; no conversion, non-default charsets/collations, descriptor charset metadata, collation comparison semantics, multiple actions, temporary tables, views, or full charset/collation catalogs |
| `FORCE` | 🟡 | Limited single-action `ALTER TABLE table_name FORCE` for persistent base tables without primary-key descriptors; performs a descriptor-driven SQLite-side physical rebuild, preserves row values and logical descriptors, reports zero affected rows/warnings, and increments only SQLite schema generation; no temporary tables, repeated or mixed ALTER actions, storage-engine defragmentation guarantees, algorithms, locks, indexes, implicit commits, or privileges |
| `DISCARD TABLESPACE` | ❌ | Tablespace discard syntax |
| `IMPORT TABLESPACE` | ❌ | Tablespace import syntax |
| `ALGORITHM` | ❌ | DEFAULT, INSTANT, INPLACE, COPY handling and diagnostics |
| `LOCK` | ❌ | DEFAULT, NONE, SHARED, EXCLUSIVE handling and diagnostics |
