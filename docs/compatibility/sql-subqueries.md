# SQL subqueries

Subquery, quantified comparison, correlation, and derived table materialization compatibility.

| Feature | Status | Notes |
| --- | --- | --- |
| Scalar subqueries | 🟡 | Limited no-source and `FROM DUAL` scalar subqueries as projection operands and as current `CONCAT()` operands, with one inner scalar value from the supported `DATABASE()`/`SCHEMA()`, integer/boolean/`NULL`, and system-variable read subset; limited uncorrelated table-backed scalar subqueries are supported only as single-table `UPDATE` assignment values, with one descriptor source column and the current descriptor `SELECT` source envelope; limited correlated `SELECT ... WHERE (SELECT COUNT(*)\|COUNT(literal) FROM descriptor_source [WHERE ...]) comparison integer_literal` predicates are supported for descriptor-backed SELECT filters, including the current joined outer-source predicate envelope; multi-column inner projections return MySQL-compatible `1241 / 21000`, matched multi-row assignment subqueries return `1242 / 21000`, and same-table update sources return `1093 / HY000`; no correlated scalar subqueries outside the COUNT predicate subset, derived-table, row, quantified, general DML-assignment, or arbitrary expression subqueries |
| Row subqueries | ❌ | Row constructors and multi-column comparison semantics |
| `EXISTS` subqueries | 🟡 | Limited descriptor-driven `SELECT ... WHERE [NOT] EXISTS (...)` and single-table `UPDATE ... WHERE [NOT] EXISTS (...)` predicates for one outer base table and tableless/`DUAL` or one-table inner subqueries with optional limited predicate, simple correlated integer equality/null-safe equality, and `LIMIT row_count`; SELECT predicates also support limited descriptor-backed inner `INNER JOIN` sources with equality `ON` conditions and correlated integer equality to the outer row; also supports uncorrelated `[NOT] EXISTS` filters for no-source/`FROM DUAL` row-scalar `INSERT ... SELECT` sources; update predicates reject same-target inner table reads with `1093 / HY000`; no scalar projection, `DELETE` predicates, joined-DML predicates, nested subqueries, derived tables, joined shapes outside the documented SELECT inner `INNER JOIN` subset, arbitrary expressions, or optimizer parity |
| `IN` subqueries | 🟡 | Limited descriptor-driven `SELECT ... WHERE descriptor_column [NOT] IN (SELECT [DISTINCT] descriptor_column FROM descriptor_source [WHERE ...])`, SELECT-style `(SELECT descriptor_column FROM descriptor_source [WHERE ...]) [NOT] IN (literal_list)` predicates, and single-table `UPDATE ... WHERE descriptor_column [NOT] IN (...)` predicates; SELECT predicates support the current single-table or joined outer source envelope and inner one-table or descriptor-equality `INNER JOIN` / `LEFT JOIN` source envelope, while UPDATE predicates keep the single-table target envelope and reject same-target inner reads, including joined inner sources, with `1093 / HY000`; supports compatible integer-family and ASCII nonbinary string-family descriptor columns, optional limited inner predicates, simple correlated integer equality/null-safe equality, MySQL `NULL` membership semantics, schema-qualified names, `1241 / 21000` for multi-column inner projections, and MySQL-compatible `1235 / 42000` for inner `LIMIT`; scalar-subquery membership uses the selected descriptor column to convert literal-list values but does not yet enforce MySQL's multi-row scalar-subquery `1242 / 21000` diagnostic; no tableless/`DUAL`, wildcard, row-constructor, quantified, `DELETE` predicate, joined-DML predicate, nested, derived-table, ordered, limited, aggregate, grouped, expression, function, parameter, or arbitrary conversion subqueries |
| `ANY` / `SOME` / `ALL` subqueries | ❌ | Quantified comparison semantics |
| Derived table materialization/merge | ❌ | Optimizer-visible semantics and metadata results |
