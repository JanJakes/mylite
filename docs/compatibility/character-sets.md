# Character sets

MyLite exposes the full MySQL 8.4.9 character-set catalog through
`SHOW CHARACTER SET` and `INFORMATION_SCHEMA.CHARACTER_SETS`. Catalog
visibility is metadata-only unless the row notes explicitly describe DDL,
conversion, storage, or comparison behavior.
