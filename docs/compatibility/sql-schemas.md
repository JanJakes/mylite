# SQL schemas

Database/schema selection and DDL compatibility.

| Feature | Status | Notes |
| --- | --- | --- |
| `ALTER DATABASE` / `ALTER SCHEMA` | 🟡 | Limited descriptor-owned default charset/collation updates for admitted `utf8mb4` and `binary` schema defaults, named schemas, and selected-schema forms; reports MySQL-compatible affected rows and diagnostics for missing default schema, unknown schemas, protected built-in schemas, reserved `_mylite_*` names, unknown charsets/collations, mismatched collations, and conflicting charset declarations; no encryption options, filesystem directories, privileges, conversion, comparison semantics, or mutable server-global defaults |
| `CREATE DATABASE` / `CREATE SCHEMA` | 🟡 | Creates persistent MyLite catalog schemas with optional `IF NOT EXISTS` and limited `DEFAULT CHARACTER SET` / `CHARSET` / `COLLATE` options for admitted `utf8mb4` and `binary` defaults; existing-schema `IF NOT EXISTS` validates supplied options, succeeds as a no-op with stored `Note 1007`, affected rows `1`, and no catalog or SQLite schema mutation; creating protected built-in schemas such as `information_schema`, `mysql`, `performance_schema`, and `sys` is rejected with deterministic MySQL-shaped diagnostics; no encryption options, privileges, filesystem directories, or writable system schema behavior |
| `DROP DATABASE` / `DROP SCHEMA` | 🟡 | Drops MyLite catalog schemas, descriptor-owned base tables, and baseline view descriptors with optional `IF EXISTS`; existing-schema drops reuse descriptor-driven base-table cleanup and metadata-only view cleanup, missing-schema `IF EXISTS` succeeds with a statement warning count but no stored `SHOW WARNINGS` row or `@@warning_count`, dropping protected built-in schemas is rejected, and limited user-transaction implicit commit follows the SQL transaction subset; no privileges, filesystem directory cleanup, `RESTRICT`/`CASCADE`, or non-table/view objects |
| `SHOW CREATE DATABASE` / `SHOW CREATE SCHEMA` | 🟡 | Renders MyLite schema descriptors with stored default charset/collation metadata and fixed MySQL 8.4.9 default-encryption text; `binary` defaults render without an explicit `COLLATE binary` clause; no `IF NOT EXISTS`, encryption mutation, privileges, built-in system schema rendering, or mutable `sql_quote_show_create` |
| `USE` | 🟡 | Selects existing MyLite catalog schemas, including schemas created through public SQL, and synthetic built-in schemas `information_schema`, `mysql`, `performance_schema`, and `sys` without creating catalog descriptors; limited `DATABASE()` / `SCHEMA()` scalar selects observe the selected schema, limited metadata `SELECT` forms can resolve unqualified `INFORMATION_SCHEMA` tables while `information_schema` is selected, and limited `@@character_set_database` / `@@collation_database` reads expose descriptor defaults, fixed server fallback defaults, or synthetic built-in schema defaults |
