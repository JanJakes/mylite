# Comparison functions

Expression helpers driven by comparison, ordering, or NULL-test semantics.

| Function | Status | Notes |
| --- | --- | --- |
| `GREATEST()` | 🟡 | Limited no-source, `DUAL`, `DO`, `SET @user_variable`, source-free DML value positions, and single-table row-scalar `SELECT` projection over all-string or all-integer argument lists with `NULL`, ASCII string literals, signed-64 integer/boolean literals, supported descriptor columns, and supported row arithmetic integer operands; also admitted as a current row-control-flow value operand, as an integer-domain row-control-flow condition operand, and as a current string-concatenation value operand. Returns `NULL` if any argument is `NULL`, otherwise the maximum argument using numeric or ASCII `utf8mb4_0900_ai_ci` comparison; limited descriptor-backed `WHERE` truth, comparison, `IS [NOT] NULL`, and `[NOT] BETWEEN` row-scalar predicates; no mixed domains, decimals/floats, binary strings, non-ASCII collation parity, string-domain row-control-flow truth conversion, DML assignments outside the constant descriptor-backed value subset, ordering/grouping expressions, or general expression metadata |
| `INTERVAL()` | 🟡 | Limited no-source, `DUAL`, `DO`, and single-table row-scalar `SELECT` projection over sorted integer-domain thresholds; search argument may be a signed-64 integer/boolean/`NULL` scalar value or an integer-family descriptor column, thresholds are signed-64 integer/boolean literals, `NULL` search returns `-1`, and duplicate thresholds count independently; no string/decimal/float coercion, `NULL` thresholds, unsorted thresholds, threshold columns, predicates, ordering/grouping expressions, DML assignments, nested functions, or general expression metadata |
| `ISNULL()` | 🟡 | Limited no-source/`DUAL` scalar, `DO`, descriptor-backed truth/comparison/`IS` predicates, and single-table row-scalar projection support over documented scalar values, descriptor values, supported row arithmetic values, and one nested row-control-flow layer; returns integer `1` for `NULL` and `0` otherwise; no ordering/grouping expressions, DML assignments, binary string/`BIT`/approximate/JSON column operands, table-backed subqueries, warning-producing expressions outside evaluated row arithmetic, or expression metadata |
| `LEAST()` | 🟡 | Limited no-source, `DUAL`, `DO`, `SET @user_variable`, source-free DML value positions, and single-table row-scalar `SELECT` projection over all-string or all-integer argument lists with `NULL`, ASCII string literals, signed-64 integer/boolean literals, supported descriptor columns, and supported row arithmetic integer operands; also admitted as a current row-control-flow value operand, as an integer-domain row-control-flow condition operand, and as a current string-concatenation value operand. Returns `NULL` if any argument is `NULL`, otherwise the minimum argument using numeric or ASCII `utf8mb4_0900_ai_ci` comparison; limited descriptor-backed `WHERE` truth, comparison, `IS [NOT] NULL`, and `[NOT] BETWEEN` row-scalar predicates; no mixed domains, decimals/floats, binary strings, non-ASCII collation parity, string-domain row-control-flow truth conversion, DML assignments outside the constant descriptor-backed value subset, ordering/grouping expressions, or general expression metadata |
