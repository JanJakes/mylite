# Feature specifications

Substantive MySQL compatibility work starts with a feature specification under
this directory.

Each feature should use a lower-case, hyphenated directory name:

```text
docs/specs/<feature-slug>/specs.md
```

Feature specs should capture MyLite's independently authored design, syntax,
semantics, metadata, errors, warnings, SQL modes, edge cases, storage/runtime
impact, MyLite compatibility decisions, and MySQL 8.4.9 runtime-verified test
expectations.
