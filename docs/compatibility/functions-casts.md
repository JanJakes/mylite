# Cast functions

Explicit conversion functions.

| Function | Status | Notes |
| --- | --- | --- |
| `CAST()` | 🟡 | Limited no-source, `FROM DUAL`, and `DO` `CAST(value AS BINARY)`, `CAST(value AS CHAR)`, `CAST(value AS SIGNED [INTEGER\|INT])`, and `CAST(value AS UNSIGNED [INTEGER\|INT])` for ordinary string, decimal integer, `TRUE`/`FALSE`, and `NULL` scalar values, including MySQL-runtime-verified string-to-integer truncation/complement warnings for the admitted scalar envelope; binary column storage is tracked separately under binary string types; no length-bearing binary or character casts, explicit character-set clauses, temporal/decimal/float/JSON/spatial/other targets, table-backed casts, predicates, DML assignments, expression defaults, embedded-NUL scalar delivery, or protocol-grade metadata |
| `CONVERT()` | 🟡 | Limited no-source, `FROM DUAL`, and `DO` `CONVERT(value, BINARY)`, `CONVERT(value, CHAR)`, `CONVERT(value, SIGNED [INTEGER\|INT])`, and `CONVERT(value, UNSIGNED [INTEGER\|INT])` for ordinary string, decimal integer in the current scalar envelope, `TRUE`/`FALSE`, and `NULL` scalar values, existing `CONVERT('string' USING BINARY)` for ordinary NUL-free string literals, and scalar `CONVERT(value USING utf8mb4\|utf8\|utf8mb3\|latin1)` including quoted charset names for ordinary string, decimal integer in the same scalar envelope, `TRUE`/`FALSE`, and `NULL` scalar values; `utf8` and `utf8mb3` emit MySQL-compatible deprecation warnings, `latin1` is limited to ASCII scalar values, and result metadata is visible through `CHARSET()`, `COLLATION()`, `COERCIBILITY()`, and scalar postfix `COLLATE` for admitted `utf8mb4`, `utf8mb3`, and `latin1` collations. No length-bearing `BINARY(N)`/`CHAR(N)`, explicit character-set target clauses outside the listed scalar `USING` names, temporal/decimal/float/JSON/spatial/other targets, table-backed conversion, predicates, DML assignments, expression defaults, general transcoding, embedded-NUL scalar delivery, or protocol-grade metadata |
