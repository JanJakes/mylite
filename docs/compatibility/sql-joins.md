# SQL joins

Table reference, join syntax, join semantics, lateral derived table, and join metadata compatibility.

| Feature | Status | Notes |
| --- | --- | --- |
| Table references | 🟡 | Limited descriptor-backed base-table references in plain `SELECT` with optional `AS alias` or bare aliases, limited validated/no-op index hints, two-source outer joins, multi-source inner/cartesian join chains, and pure multi-source comma lists; no mixed comma/explicit join precedence, derived tables, table functions, parenthesized table references, or partitions |
| Inner joins | 🟡 | Limited `JOIN`, `INNER JOIN`, `CROSS JOIN`, and comma joins in descriptor-backed plain `SELECT`, including three-or-more-source inner/cartesian chains and pure comma lists, with optional one-column same-family integer or ASCII string descriptor equality `ON`, no `ON` for cartesian products, or limited same-family descriptor-column equality in `WHERE` for comma/inner join filtering; supports projection, qualified wildcards, `WHERE`, descriptor-column `ORDER BY`, `LIMIT`, and limited `SQL_CALC_FOUND_ROWS` over joined sources, plus existing grouped aggregates over the prior two-source envelope; no `USING`, mixed comma/explicit precedence, mixed-type `ON`/column-to-column comparisons, arbitrary `ON` predicates, arbitrary column-to-column `WHERE`, multi-source outer joins, distinct joins, full grouping, or expression projection |
| Left outer joins | 🟡 | Limited two-source `LEFT JOIN` and `LEFT OUTER JOIN` in descriptor-backed `SELECT`, with required one-column same-family integer or ASCII string descriptor equality `ON`; preserves left rows, null-extends unmatched right descriptor columns, and supports projection, `WHERE`, descriptor-column `ORDER BY`, and `LIMIT` over joined sources, plus limited grouped aggregates with one integer descriptor group column and one aggregate result; no `USING`, natural joins, full outer joins, mixed-type `ON` comparisons, arbitrary `ON` predicates, multi-source outer chains, distinct joins, full grouping, or expression projection |
| Right outer joins | 🟡 | Limited two-source `RIGHT JOIN` and `RIGHT OUTER JOIN` in plain descriptor-backed `SELECT`, with required one-column same-family integer or ASCII string descriptor equality `ON`; preserves right rows, null-extends unmatched left descriptor columns, keeps `SELECT *` syntactic left-then-right column order, and supports projection, `WHERE`, descriptor-column `ORDER BY`, and `LIMIT` over joined sources; no `USING`, natural joins, joined DML right joins, grouped right joins, full outer joins, mixed-type `ON` comparisons, arbitrary `ON` predicates, multi-source outer chains, distinct joins, full grouping, or expression projection |
| Full outer joins | ❌ | MySQL-style diagnostics for unsupported `FULL OUTER JOIN` syntax; no full outer null-extension emulation. Plain `FULL JOIN` is not treated as a full-outer operator in the current subset because MySQL can parse `FULL` as a source alias followed by an ordinary `JOIN` |
| Natural joins | ❌ | NATURAL INNER/LEFT/RIGHT JOIN column matching and metadata |
| `STRAIGHT_JOIN` | ❌ | Join-order forcing syntax and optimizer interaction |
| Lateral derived tables | ❌ | LATERAL derived table correlation rules |
