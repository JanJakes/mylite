| `KILL` | ❌ | Connection/query kill syntax, diagnostics |
| `RESET` | ❌ | RESET variants and diagnostics |
| `RESET PERSIST` | ❌ | Persisted system variable reset syntax |
| `RESTART` | ❌ | Server restart syntax diagnostics |
| `SHUTDOWN` | ❌ | Server shutdown syntax diagnostics |
