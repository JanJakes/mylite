# JSON functions and operators

JSON construction, extraction, mutation, aggregation, validation, and storage-observable functions.

| Function or operator | Status | Notes |
| --- | --- | --- |
| `->` | 🟡 | Limited single-table row-scalar projection shorthand for `JSON_EXTRACT(column, path)` over unqualified or qualified descriptor columns and simple path string literals; no literal/function left operands, wildcards/ranges, predicates, expression ordering, DML assignment expressions, or full expression support |
| `->>` | 🟡 | Limited single-table row-scalar projection shorthand for `JSON_UNQUOTE(JSON_EXTRACT(column, path))` over unqualified or qualified descriptor columns and simple path string literals; no literal/function left operands, wildcards/ranges, predicates, expression ordering, DML assignment expressions, or full expression support |
| `JSON_ARRAY()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over admitted SQL string, signed-64 integer, boolean, `NULL`, JSON descriptor, integer descriptor, boolean-like integer descriptor, and nonbinary string descriptor values; JSON columns construct as JSON values while string columns construct as JSON strings; no nested construction, arbitrary expression operands, predicates, ordering/grouping expressions, key-target assignments, aggregation, mutation, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_ARRAY_APPEND()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor documents, simple path string/`NULL` literals, and admitted string, signed-64 integer, boolean, `NULL`, JSON descriptor, integer descriptor, boolean-like integer descriptor, and nonbinary string descriptor values; no-source scalar values additionally admit current `JSON_EXTRACT()`, `JSON_ARRAY()`, and `JSON_OBJECT()` results, while row-scalar values admit current `JSON_ARRAY()` and `JSON_OBJECT()` results. Supports array append, selected nonarray autowrap, root autowrap, missing-path no-op, and left-to-right path/value pairs; no stored partial updates, wildcard/range paths, recursive mutation values, row-scalar `JSON_EXTRACT()` values, arbitrary expression arguments, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_ARRAY_INSERT()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor documents, simple array-cell path string/`NULL` literals, and admitted string, signed-64 integer, boolean, `NULL`, JSON descriptor, integer descriptor, boolean-like integer descriptor, and nonbinary string descriptor values; no-source scalar values additionally admit current `JSON_EXTRACT()`, `JSON_ARRAY()`, and `JSON_OBJECT()` results, while row-scalar values admit current `JSON_ARRAY()` and `JSON_OBJECT()` results. Supports array insertion/append, missing or nonarray parent no-op, left-to-right path/value pairs, and MySQL-shaped non-array-cell path diagnostics; no stored partial updates, wildcard/range paths, recursive mutation values, row-scalar `JSON_EXTRACT()` values, arbitrary expression arguments, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_ARRAYAGG()` | ⚪ | Parser-admitted generic function and aggregate-window placeholder with explicit unsupported diagnostics; no executable JSON aggregation |
| `JSON_CONTAINS()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar projection/predicate containment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor document/candidate values, with optional simple path string/`NULL` literal and current JSON number subset; no wildcard/range paths, arbitrary expression arguments, binary strings, numeric normalization across equivalent decimal/exponent spellings, ordering/grouping expressions, DML assignment expressions, mutation, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_CONTAINS_PATH()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar projection/predicate path existence over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor document values with case-insensitive literal `one`/`all` and simple path string/`NULL` literals; no wildcard/range/multi-match paths, arbitrary expression arguments, path columns, binary strings, ordering/grouping expressions, DML assignment expressions, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_DEPTH()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar depth over SQL string literals, `NULL`, JSON columns, nonbinary string columns, and supported `JSON_EXTRACT()` results; scalar, array, object, nested, duplicate-key-normalized, invalid-text, binary-string, and argument-count behavior is MySQL-runtime-verified for the baseline subset; no arbitrary expression contexts, grouped ordering, key-target assignments, or full protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_EXTRACT()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar projection with one JSON document operand and one simple path string literal; supports SQL string literals, `NULL`, JSON columns, and nonbinary string columns, returning JSON text or SQL `NULL`; limited descriptor-backed predicates, row-scalar `IN`, non-grouped single-table scalar-result `ORDER BY`, and compatible non-key single-table `UPDATE` assignment are admitted; no multiple paths, wildcards/ranges, nonscalar JSON ordering, grouped ordering, key-target assignments, arbitrary expressions, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_INSERT()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor documents, simple path string/`NULL` literals, and admitted string, signed-64 integer, boolean, `NULL`, JSON descriptor, integer descriptor, boolean-like integer descriptor, and nonbinary string descriptor values; no-source scalar values additionally admit current `JSON_EXTRACT()`, `JSON_ARRAY()`, and `JSON_OBJECT()` results, while row-scalar values admit current `JSON_ARRAY()` and `JSON_OBJECT()` results. Supports existing-path no-op, member insertion, array append, scalar nonzero-index autowrap, duplicate paths left-to-right, missing-intermediate no-op, and root no-op; no stored partial updates, wildcard/range paths, recursive `JSON_INSERT()` values, row-scalar `JSON_EXTRACT()` values, arbitrary expression arguments, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_KEYS()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string literals, `NULL`, JSON columns, nonbinary string columns, and supported `JSON_EXTRACT()` results, with optional simple path string literal; no wildcards, multi-match paths, arbitrary expressions, predicates, ordering/grouping expressions, key-target assignments, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_LENGTH()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar shallow length over SQL string literals, `NULL`, JSON columns, nonbinary string columns, and supported `JSON_EXTRACT()` results, with optional simple path string literal; limited descriptor-backed predicates, row-scalar `IN`, non-grouped single-table `ORDER BY`, and compatible non-key single-table `UPDATE` assignment are admitted; no wildcards, multi-match paths, arbitrary expressions, grouped ordering, key-target assignments, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_MERGE()` | 🟡 | Deprecated synonym for `JSON_MERGE_PRESERVE()` over the documented baseline document-argument envelope; emits MySQL warning `1287`; no arbitrary expression contexts, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal document values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_MERGE_PATCH()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, nonbinary string descriptor, and current JSON function document producers. Supports RFC-style patch replacement/removal/recursive object merge and MySQL SQL-`NULL` validation behavior; no arbitrary expression contexts, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal document values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_MERGE_PRESERVE()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, nonbinary string descriptor, and current JSON function document producers. Supports array concatenation, scalar autowrap, duplicate-key preservation, recursive object merge, and MySQL first-SQL-`NULL` short-circuit behavior; no arbitrary expression contexts, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal document values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_OBJECT()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment with zero or even key/value arguments; keys may be admitted string, signed-64 integer, boolean, or non-`NULL` descriptor integer/nonbinary string values, values follow `JSON_ARRAY()` limits including JSON descriptor values, duplicate keys keep the last value, and `NULL` keys report MySQL-compatible `3158`; no nested construction, arbitrary expression operands, JSON-column keys, predicates, ordering/grouping expressions, key-target assignments, aggregation, mutation, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_OBJECTAGG()` | ⚪ | Parser-admitted generic function and aggregate-window placeholder with explicit unsupported diagnostics; no executable JSON object aggregation |
| `JSON_OVERLAPS()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar projection/predicate overlap checks over SQL string/`NULL`, JSON descriptor, nonbinary string descriptor, and supported `JSON_EXTRACT()` document values; supports scalar equality, array element intersection, array/nonarray equality, and shared object key/value equality over the current JSON DOM subset; no arbitrary expression arguments, binary strings, numeric normalization across equivalent decimal/exponent spellings, optimizer use, ordering/grouping expressions, DML assignment expressions, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_PRETTY()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar pretty rendering over SQL string literals, `NULL`, JSON columns, nonbinary string columns, and supported `JSON_EXTRACT()` results; two-space object/array formatting, object display order, scalar passthrough, invalid-text, binary-string, and argument-count behavior is MySQL-runtime-verified for the baseline subset; no arbitrary expression contexts, grouped ordering, key-target assignments, or full protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_QUOTE()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar string quoting over SQL string literals, `NULL`, and nonbinary string descriptor columns; returns JSON string literal text for non-`NULL` strings and SQL `NULL` for SQL `NULL`; limited descriptor-backed predicates, non-grouped single-table `ORDER BY`, and compatible non-key single-table `UPDATE` assignment are admitted; no binary strings, JSON/numeric/boolean/temporal inputs, arbitrary expressions, grouped ordering, key-target assignments, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_REMOVE()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor documents with simple path string/`NULL` literals. Supports object-member and array-element removal, missing-path no-op, duplicate paths left-to-right, scalar final-leg no-op, and MySQL-compatible root-path rejection; no stored partial updates, wildcard/range paths, path column arguments, arbitrary expression arguments, predicates, ordering/grouping expressions, key-target assignments, binary strings, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
| `JSON_REPLACE()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor documents, simple path string/`NULL` literals, and admitted string, signed-64 integer, boolean, `NULL`, JSON descriptor, integer descriptor, boolean-like integer descriptor, and nonbinary string descriptor values; no-source scalar values additionally admit current `JSON_EXTRACT()`, `JSON_ARRAY()`, and `JSON_OBJECT()` results, while row-scalar values admit current `JSON_ARRAY()` and `JSON_OBJECT()` results. Supports root replacement, existing member/array/scalar-index-zero replacement, duplicate paths left-to-right, and missing-path no-op; no stored partial updates, wildcard/range paths, recursive `JSON_REPLACE()` values, row-scalar `JSON_EXTRACT()` values, arbitrary expression arguments, predicates, ordering/grouping expressions, key-target assignments, binary strings, decimal/float/temporal values, or protocol metadata beyond limited scalar/row-scalar result-column metadata |

| `JSON_SET()` | 🟡 | Limited no-source/`DUAL`/`DO`, single-table row-scalar projection, and compatible non-key single-table `UPDATE` assignment over SQL string/`NULL`, JSON descriptor, and nonbinary string descriptor documents, simple path string/`NULL` literals, and admitted string, signed-64 integer, boolean, `NULL`, JSON descriptor, integer descriptor, boolean-like integer descriptor, and nonbinary string descriptor values; no-source scalar values additionally admit current `JSON_EXTRACT()`, `JSON_ARRAY()`, and `JSON_OBJECT()` results, while row-scalar values admit current `JSON_ARRAY()` and `JSON_OBJECT()` results. | `JSON_STORAGE_SIZE()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar size over SQL string literals, `NULL`, JSON columns, nonbinary string columns, and supported `JSON_EXTRACT()` / mutation results, using a MyLite-owned small-document MySQL binary-layout estimate for the current JSON DOM subset; no persisted MySQL binary JSON storage or arbitrary expression contexts |
| `JSON_TABLE()` | ❌ | Return data from a JSON expression as a relational table |
| `JSON_TYPE()` | 🟡 | Limited no-source/`DUAL`/`DO` and single-table row-scalar value type labels over SQL string literals, `NULL`, JSON columns, nonbinary string columns, and supported `JSON_EXTRACT()` results; currently reports `OBJECT`, `ARRAY`, `BOOLEAN`, `NULL`, `STRING`, signed-integer `INTEGER`, and finite decimal/exponent `DOUBLE`; limited descriptor-backed predicates, non-grouped single-table `ORDER BY`, and compatible non-key single-table `UPDATE` assignment are admitted; no arbitrary expressions, grouped ordering, key-target assignments, or protocol metadata beyond limited scalar/row-scalar result-column metadata |
