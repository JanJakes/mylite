Unless a row says otherwise, nested-function gaps refer to functions outside
the supported row-scalar value-argument subset. That subset includes currently
supported `CONCAT()` / `CONCAT_WS()`, string helpers, JSON helpers, numeric
helpers, conversion helpers, control-flow helpers, session values, and system
