# Control-flow functions

Conditional expression helpers.

| Function | Status | Notes |
| --- | --- | --- |
| `CASE` | 🟡 | Limited no-source/`DUAL` scalar searched and simple `CASE`, `DO`, single-table searched row-scalar projection, narrow joined simple row-scalar projection over integer descriptor/literal operands, and hidden `ORDER BY` rank keys over the current row-control-flow condition/value subset, including supported row arithmetic, integer-domain `GREATEST()` / `LEAST()`, `LIKE`, `AND`, and `OR`; row values also admit current `GREATEST()` / `LEAST()` row expressions. No deeper nested `CASE`, `CASE` as a larger scalar operand, general predicates, DML assignments, unsupported value domains, string-domain extrema truth conversion, subqueries, side effects beyond evaluated expression warnings, full result type aggregation, or expression metadata |
| `COALESCE()` | 🟡 | Limited scalar, `DO`, `SET @user_variable`, source-free DML value, descriptor-backed truth/comparison/`IS`/range/membership predicates, and single-table row-scalar projection support over the documented scalar values, descriptor values, supported row arithmetic values, current `GREATEST()` / `LEAST()` row values, and one nested row-control-flow layer; no ordering/grouping expressions, broad DML assignments, table-backed subqueries, binary string/`BIT`/approximate/JSON column operands, side effects outside evaluated arithmetic warnings, or expression metadata |
| `IF()` | 🟡 | Limited scalar, `DO`, `SET @user_variable`, source-free DML value, descriptor-backed truth/comparison/`IS`/range predicates, and single-table row-scalar projection support; row conditions admit descriptor integer columns, integer/boolean/`NULL` literals, row-backed `ISNULL()`, supported row arithmetic truth values, integer-domain `GREATEST()` / `LEAST()`, and documented `LIKE`/logical atoms, while row values admit documented descriptor/scalar values, supported row arithmetic, current `GREATEST()` / `LEAST()` row values, and one nested row-control-flow layer; no ordering/grouping expressions, broad DML assignments, string/decimal truth conversion outside row arithmetic, string-domain extrema truth conversion, table-backed subqueries, unsupported column families, side effects outside evaluated arithmetic warnings, or expression metadata |
| `IFNULL()` | 🟡 | Limited scalar, `DO`, `SET @user_variable`, source-free DML value, descriptor-backed truth/comparison/`IS`/range/membership predicates, and single-table row-scalar projection support over the documented scalar values, descriptor values, supported row arithmetic values, current `GREATEST()` / `LEAST()` row values, and one nested row-control-flow layer; no ordering/grouping expressions, broad DML assignments, table-backed subqueries, binary string/`BIT`/approximate/JSON column operands, side effects outside evaluated arithmetic warnings, or expression metadata |
| `NULLIF()` | 🟡 | Limited scalar, `DO`, `SET @user_variable`, source-free DML value, descriptor-backed truth/comparison/`IS`/range predicates, and single-table row-scalar projection over same-domain admitted integer/string-like values plus supported row arithmetic values and current `GREATEST()` / `LEAST()` row values; admitted string comparisons use MyLite's registered ASCII `utf8mb4_0900_ai_ci` collation; no ordering/grouping expressions, broad DML assignments, mixed unsupported row domains, table-backed subqueries, binary string/`BIT`/approximate/JSON column operands, side effects outside evaluated arithmetic warnings, first-argument double-evaluation semantics, or expression metadata |
