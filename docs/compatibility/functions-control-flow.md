# Control-flow functions

Conditional expression helpers.

| Function | Status | Notes |
| --- | --- | --- |
| `COALESCE()` | ❌ | Return first non-NULL argument |
| `IF()` | ❌ | If/else construct |
| `IFNULL()` | ❌ | Null if/else construct |
| `NULLIF()` | ❌ | Return NULL if expr1 = expr2 |
