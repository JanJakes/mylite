| --- | --- | --- |

| `ALTER RESOURCE GROUP` | ❌ | Resource group modification syntax |
| `DROP RESOURCE GROUP` | ❌ | Resource group deletion syntax |
| `SET RESOURCE GROUP` | ❌ | Thread assignment to resource groups |
