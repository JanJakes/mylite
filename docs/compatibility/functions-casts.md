# Cast functions

Explicit conversion functions.

| Function | Status | Notes |
| --- | --- | --- |
| `CAST()` | 🟡 | Limited no-source, `FROM DUAL`, `DO`, and single-table row-scalar `SELECT` `CAST(value AS BINARY)`, `CAST(value AS CHAR)`, `CAST(value AS DATE)`, `CAST(value AS SIGNED [INTEGER\|INT])`, and `CAST(value AS UNSIGNED [INTEGER\|INT])`; no-source scalar contexts additionally admit placeholder `BINARY(N)`, `CHAR(N) [CHARACTER SET name] [BINARY]`, `NCHAR(N)`, `NATIONAL CHAR(N)`, `NATIONAL CHARACTER(N)`, `TIME`, `DATETIME`, `TIMESTAMP`, `DECIMAL[(precision[, scale])]`, `FLOAT[(precision[, scale])]`, `REAL`, `DOUBLE [PRECISION]`, and `JSON` targets. Scalar contexts admit ordinary string, decimal integer, `TRUE`/`FALSE`, and `NULL` values, while row-scalar contexts additionally admit descriptor integer-family and nonbinary string-family columns plus supported folded session scalar values. Placeholder scalar targets support byte truncation without NUL padding, canonical date/time/datetime extraction for canonical datetime strings, decimal scale formatting, approximate-target text passthrough, and JSON normalization; row-scalar projections, comparison-left predicates, and single-table `ORDER BY` expression keys remain limited to the existing bare binary/character/signed/unsigned/date metadata surface, with joined `ORDER BY` support limited to character conversion keys. Comparison-left predicates additionally admit WordPress-style `CAST(... AS BINARY) REGEXP/RLIKE [BINARY] 'pattern'`, `CAST(... AS SIGNED) [NOT] BETWEEN` quoted integer bounds, and `CAST(... AS DECIMAL(M,D))` comparison, `[NOT] BETWEEN`, or `[NOT] LIKE` predicates with finite decimal string literals or string patterns. String-to-integer conversions produce MySQL-runtime-verified truncation/complement warnings for admitted string values; binary column storage is tracked separately under binary string types. No spatial targets, binary string or `BIT` row operands, general expression operands, DML assignments, expression defaults, embedded-NUL scalar delivery, full temporal/numeric cast semantics, full exact-decimal predicate arithmetic, or full protocol-grade metadata |
| `CONVERT()` | 🟡 | Limited no-source, `FROM DUAL`, `DO`, and single-table row-scalar `SELECT` `CONVERT(value, BINARY)`, `CONVERT(value, CHAR)`, `CONVERT(value, DATE)`, `CONVERT(value, SIGNED [INTEGER\|INT])`, `CONVERT(value, UNSIGNED [INTEGER\|INT])`, `CONVERT(value USING BINARY)`, and `CONVERT(value USING utf8mb4\|utf8\|utf8mb3\|latin1)` including quoted charset names for the charset forms; no-source scalar contexts additionally admit placeholder `BINARY(N)`, `CHAR(N)`, `TIME`, `DATETIME`, `TIMESTAMP`, `DECIMAL[(precision[, scale])]`, `FLOAT[(precision[, scale])]`, `REAL`, `DOUBLE [PRECISION]`, and `JSON` type targets. Scalar contexts admit ordinary string, decimal integer in the current scalar envelope, `TRUE`/`FALSE`, and `NULL` values, while row-scalar contexts additionally admit descriptor integer-family and nonbinary string-family columns plus supported folded session scalar values. Placeholder scalar targets support byte truncation without NUL padding, canonical date/time/datetime extraction for canonical datetime strings, decimal scale formatting, approximate-target text passthrough, and JSON normalization; row-scalar projections, comparison-left predicates, and single-table `ORDER BY` expression keys remain limited to the existing bare binary/character/signed/unsigned/date metadata surface, with joined `ORDER BY` support limited to character conversion keys. `utf8` and `utf8mb3` emit MySQL-compatible deprecation warnings, `latin1` is limited to ASCII scalar values, and result metadata is visible through result columns plus current `CHARSET()`, `COLLATION()`, `COERCIBILITY()`, and scalar postfix `COLLATE` surfaces. No explicit character-set type target clauses outside `CAST(... AS CHAR ...)`, spatial targets, binary string or `BIT` row operands, general expression operands, DML assignments, expression defaults, general transcoding, embedded-NUL scalar delivery, full temporal/numeric cast semantics, or full protocol-grade metadata |
